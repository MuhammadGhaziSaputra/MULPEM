# 📚 Bank Soal & Rubrik Umpan Balik Lengkap

## Multimedia Pembelajaran Interaktif — Sistem Komputer Fase E (Kelas X)
Dokumen ini memuat **30 butir soal lengkap** (15 Kuis Formatif berkode `K` dan 15 Latihan Soal berkode `L`) beserta kunci jawaban, tipe interaksi, level kognitif, umpan balik benar/salah, dan petunjuk (*hint*).

---

## 1. Aturan Penilaian & Pengacakan

1. **Skor Ketercapaian TP (0–100):** Hanya dihitung dari kuis formatif (`K`) pada **percobaan pertama**.
2. **Poin Bonus:** Latihan soal (`L`) memberikan bonus 2 poin per butir jika dijawab benar.
3. **Pengacakan Opsi:** Semua opsi pilihan ganda dan urutan pasangan pada soal menjodohkan **wajib diacak** saat ditampilkan kepada pengguna.
4. **Pola Umpan Balik:**
   - **Jawaban Benar:** Penjelasan alasan kebenaran (maksimal 2 kalimat).
   - **Jawaban Belum Tepat:** Letak kekeliruan, saran perbaikan, serta petunjuk (*hint*).

## 2. Unit 1: Alur Input – Process – Output (IPO)

### 2.1 Kuis Formatif Unit 1

#### [K1-1] Prinsip Kerja Komputer (C2 - Pilihan Ganda)
- **Pertanyaan:** Pernyataan manakah yang paling tepat tentang alur kerja komputer?
  - A. Komputer menerima data (input), mengolahnya (proses), lalu menampilkan hasil (output). *(Kunci)*
  - B. Komputer mengolah data lebih dulu, baru menerimanya dari pengguna.
  - C. Komputer hanya menampilkan data tanpa mengolahnya.
  - D. Output adalah perangkat tempat data diolah.
- **Kunci:** A
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Urutannya selalu input, proses, lalu output: data masuk, diolah, kemudian hasilnya keluar.
- **Umpan Balik Salah:**
  - Opsi B: Urutan terbalik. Data harus masuk lebih dulu sebelum bisa diolah.
  - Opsi C: Komputer tidak hanya menampilkan data. Ada tahap proses yang mengolahnya.
  - Opsi D: Output adalah tempat hasil keluar, sedangkan pengolahan terjadi pada tahap proses di CPU.
- **Petunjuk (Hint):** Ingat urutan baku cara kerja komputer sejak data fisik dimasukkan hingga informasi tersaji.

---

#### [K1-2] Peran Keyboard (C2 - Pilihan Ganda)
- **Pertanyaan:** Kamu menekan huruf A pada keyboard dan huruf A muncul di layar. Keyboard berperan sebagai …
  - A. Input *(Kunci)*
  - B. Proses
  - C. Output
  - D. Penyimpan hasil
- **Kunci:** A
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Keyboard memasukkan data ke komputer sehingga berperan sebagai input.
- **Umpan Balik Salah:**
  - Opsi B: Keyboard tidak mengolah data, ia hanya mengirimkannya.
  - Opsi C: Yang menampilkan huruf adalah layar, bukan keyboard.
  - Opsi D: Keyboard tidak menyimpan hasil. Ia memasukkan data ke komputer.
- **Petunjuk (Hint):** Apakah keyboard berfungsi memasukkan data, mengolahnya, atau menampilkan hasilnya?

---

#### [K1-3] Urutan Alur Mengetik Huruf (C2 - Mengurutkan)
- **Pertanyaan:** Susun alur berikut dari langkah pertama sampai terakhir saat mengetik di komputer:
  - Item 1: Kamu menekan tombol huruf pada keyboard.
  - Item 2: Keyboard mengirim kode tombol ke komputer.
  - Item 3: CPU memproses kode tombol yang diterima.
  - Item 4: Huruf tampil di layar.
- **Kunci Urutan:** 1 → 2 → 3 → 4
- **Bobot Skor:** Posisi benar ÷ 4 (Misal 3 benar = 0.75)
- **Umpan Balik Benar:** Tepat! Data masuk lebih dulu, diproses oleh CPU, dan hasilnya tampil terakhir.
- **Umpan Balik Salah:** Belum tepat. Mulai dari data yang masuk (menekan tombol), lanjutkan ke pengolahan oleh CPU, dan tempatkan tampilan di layar paling akhir.
- **Petunjuk (Hint):** Pikirkan pergerakan data: dari jari pengguna → sinyal kabel → otak komputer → mata pengguna.

---

#### [K1-4] Menjodohkan Perangkat & Peran IPO (C1–C2 - Menjodohkan)
- **Pertanyaan:** Jodohkan perangkat atau bagian komputer berikut dengan perannya:
  1. Mikrofon
  2. CPU
  3. Speaker
- **Opsi Pasangan:**
  - Input
  - Proses
  - Output
- **Kunci Pasangan:**
  - Mikrofon ➔ Input
  - CPU ➔ Proses
  - Speaker ➔ Output
- **Bobot Skor:** Pasangan benar ÷ 3
- **Umpan Balik Benar:**
  - Mikrofon: Tepat! Mikrofon memasukkan suara sebagai data.
  - CPU: Tepat! CPU mengolah data.
  - Speaker: Tepat! Speaker mengeluarkan hasil berupa suara.
- **Umpan Balik Salah:**
  - Mikrofon: Mikrofon menangkap suara dari luar, jadi perannya input.
  - CPU: CPU mengolah data, jadi perannya proses.
  - Speaker: Speaker menyampaikan hasil ke pengguna, jadi perannya output.

---

#### [K1-5] Studi Kasus Scan QR Code Kantin (C2 - Pilihan Ganda Skenario)
- **Pertanyaan:** Kamu memindai kode QR pembayaran di kantin. Kamera menangkap kode, aplikasi membaca dan memeriksa kode itu, lalu layar menampilkan tulisan “Pembayaran berhasil”. Pasangan yang benar adalah …
  - A. Kamera = input, aplikasi memeriksa kode = proses, layar = output *(Kunci)*
  - B. Kamera = proses, aplikasi memeriksa kode = input, layar = output
  - C. Kamera = output, aplikasi memeriksa kode = proses, layar = input
  - D. Kamera = input, aplikasi memeriksa kode = output, layar = proses
- **Kunci:** A
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Kamera memasukkan data, aplikasi mengolahnya, dan layar menampilkan hasilnya.
- **Umpan Balik Salah:**
  - Opsi B: Kamera menangkap data dari luar, jadi ia input, bukan proses.
  - Opsi C: Kamera tidak mengeluarkan hasil, dan layar tidak memasukkan data pembayaran.
  - Opsi D: Memeriksa kode adalah pengolahan (proses), dan layar adalah tempat hasil muncul (output).
- **Petunjuk (Hint):** Bedakan perangkat fisik penangkap cahaya, program yang memverifikasi saldo, dan media penampil status.

## 3. Unit 2: Komponen Arsitektur Von Neumann

### 3.1 Kuis Formatif Unit 2

#### [K2-1] Peran Pengatur Instruksi (C1 - Pilihan Ganda)
- **Pertanyaan:** Bagian komputer yang bertugas mengatur urutan pelaksanaan instruksi dan mengarahkan komponen lain adalah …
  - A. ALU
  - B. Unit kendali (Control Unit) *(Kunci)*
  - C. Memori
  - D. Unit output
- **Kunci:** B
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Unit kendali mengatur urutan kerja komponen, seperti kepala koki di dapur restoran.
- **Umpan Balik Salah:**
  - Opsi A: ALU hanya melakukan perhitungan dan perbandingan logika, tidak mengatur urutan.
  - Opsi C: Memori menyimpan data dan instruksi, bukan mengatur alur eksekusi.
  - Opsi D: Unit output bertugas menampilkan keluaran kepada pengguna.
- **Petunjuk (Hint):** Ingat komponen yang berfungsi sebagai "polisi lalu lintas" atau pengarah di dalam prosesor.

---

#### [K2-2] Menjodohkan 4 Komponen Utama Von Neumann (C1–C2 - Menjodohkan)
- **Pertanyaan:** Jodohkan komponen berikut dengan fungsinya yang tepat:
  1. ALU (Arithmetic Logic Unit)
  2. Unit Kendali (Control Unit)
  3. Memori Utama (RAM)
  4. Unit Output
- **Opsi Pasangan:**
  - Melakukan perhitungan matematis dan perbandingan logika
  - Mengatur urutan kerja dan mengarahkan jalannya instruksi
  - Menyimpan data dan instruksi program yang sedang berjalan
  - Menampilkan atau menyampaikan hasil olahan kepada pengguna
- **Kunci:**
  - ALU ➔ Melakukan perhitungan matematis dan perbandingan logika
  - Unit Kendali ➔ Mengatur urutan kerja dan mengarahkan jalannya instruksi
  - Memori Utama ➔ Menyimpan data dan instruksi program yang sedang berjalan
  - Unit Output ➔ Menampilkan atau menyampaikan hasil olahan kepada pengguna
- **Bobot Skor:** Pasangan benar ÷ 4
- **Umpan Balik Benar:** Tepat! Setiap komponen memiliki pembagian peran yang terdefinisi jelas dalam arsitektur Von Neumann.

---

#### [K2-3] Konsep Stored-Program Von Neumann (C2 - Pilihan Ganda)
- **Pertanyaan:** Apa gagasan utama rancangan arsitektur komputer Von Neumann (1945)?
  - A. Program (instruksi) dan data disimpan bersama di dalam satu memori utama yang sama. *(Kunci)*
  - B. Setiap program memiliki memori sendiri yang terpisah secara fisik dari data.
  - C. CPU tidak memerlukan memori untuk bekerja karena langsung terhubung ke harddisk.
  - D. Hasil pengolahan langsung dikirim ke layar tanpa pernah disimpan di memori.
- **Kunci:** A
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Karena instruksi dan data berada di memori yang sama, mengganti program kerja tidak perlu merombak rangkaian fisik sirkuit.
- **Umpan Balik Salah:**
  - Opsi B: Rancangan Harvard yang memisahkan instruksi dan data secara fisik, bukan Von Neumann.
  - Opsi C: CPU mutlak membutuhkan memori kerja untuk mengambil instruksi secara cepat.
  - Opsi D: Data hasil perhitungan selalu ditaruh kembali ke memori atau register sebelum dicetak/ditampilkan.

---

#### [K2-4] Operasi Penjumlahan Angka (C2 - Pilihan Ganda Skenario)
- **Pertanyaan:** Sebuah program komputer sedang menjumlahkan angka 25 dan 17. Bagian yang melakukan eksekusi perhitungan tersebut adalah …
  - A. Unit input
  - B. Unit kendali (CU)
  - C. ALU (Arithmetic Logic Unit) *(Kunci)*
  - D. Memori utama (RAM)
- **Kunci:** C
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! ALU adalah kalkulator di dalam CPU yang mengeksekusi operasi aritmatika dan perbandingan logika.
- **Umpan Balik Salah:**
  - Opsi A: Unit input hanya memasukkan angka 25 dan 17 dari keyboard.
  - Opsi B: CU hanya mengarahkan instruksi penjumlahan, bukan menghitung angkanya.
  - Opsi D: Memori hanya menampung angka sebelum dan sesudah dijumlahkan.

---

#### [K2-5] Bagian Penyusun CPU (C1–C2 - Pilihan Ganda)
- **Pertanyaan:** Pada model Von Neumann, Central Processing Unit (CPU) secara internal terdiri atas …
  - A. ALU dan Unit Kendali (CU) *(Kunci)*
  - B. Memori Utama dan Unit Output
  - C. Unit Input dan Unit Output
  - D. Memori Utama dan ALU
- **Kunci:** A
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! CPU = Unit Kendali + ALU. Memori utama dan I/O berada di luar CPU.
- **Umpan Balik Salah:** Komponen memori, keyboard, dan monitor berada di luar unit inti pemrosesan (CPU).

## 4. Unit 3: Siklus Instruksi Fetch – Decode – Execute

### 4.1 Kuis Formatif Unit 3

#### [K3-1] Urutan Baku Siklus Instruksi (C1 - Pilihan Ganda)
- **Pertanyaan:** Urutan tahap yang benar pada siklus instruksi komputer adalah …
  - A. Jalankan (Execute) → Ambil (Fetch) → Baca (Decode)
  - B. Ambil (Fetch) → Baca (Decode) → Jalankan (Execute) *(Kunci)*
  - C. Baca (Decode) → Ambil (Fetch) → Jalankan (Execute)
  - D. Ambil (Fetch) → Jalankan (Execute) → Baca (Decode)
- **Kunci:** B
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Urutannya selalu Ambil (Fetch) instruksi dari memori, Baca (Decode) artinya apa, lalu Jalankan (Execute).
- **Umpan Balik Salah:** Instruksi tidak bisa dijalankan atau diterjemahkan sebelum diambil dari memori. Ingat singkatan: F-D-E!

---

#### [K3-2] Peristiwa Tahap Fetch (C2 - Pilihan Ganda)
- **Pertanyaan:** Pada tahap Ambil (Fetch), apa yang dilakukan oleh sistem komputer?
  - A. Menampilkan hasil ke layar
  - B. Menerjemahkan maksud instruksi
  - C. Mengambil kode instruksi dari memori utama menuju CPU *(Kunci)*
  - D. Menghitung hasil penjumlahan pada ALU
- **Kunci:** C
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Pada tahap Ambil, instruksi biner disalin dari alamat memori RAM ke register CPU.
- **Umpan Balik Salah:** Menerjemahkan terjadi di Decode, sedangkan menghitung dan menampilkan terjadi di Execute.

---

#### [K3-3] Urutan Eksekusi "Tambahkan 3" (C2 - Mengurutkan)
- **Pertanyaan:** Terdapat instruksi mikro “Tambahkan 3”. Susun urutan siklus instruksinya dari awal hingga akhir:
  - Item 1: CPU mengambil instruksi dari memori utama.
  - Item 2: Unit kendali membaca dan menerjemahkan instruksi bahwa ada perintah penambahan nilai 3.
  - Item 3: ALU menjumlahkan nilai pada register dengan angka 3.
- **Kunci Urutan:** 1 → 2 → 3 (Ambil → Baca → Jalankan)
- **Bobot Skor:** Posisi benar ÷ 3
- **Umpan Balik Benar:** Tepat! Fetch dari memori → Decode oleh Unit Kendali → Execute oleh ALU.

---

#### [K3-4] Prediksi Setelah Instruksi Selesai (C2 - Pilihan Ganda Skenario Simulasi)
- **Pertanyaan:** Instruksi 1 (“Ambil angka 5”) baru saja selesai dijalankan di CPU. Apa yang dilakukan CPU selanjutnya?
  - A. Berhenti bekerja dan mematikan sistem
  - B. Mengulang instruksi 1 dari awal secara terus-menerus
  - C. Menampilkan hasil akhir ke layar monitor
  - D. Mengambil instruksi 2 dari memori utama (Fetch berikutnya) *(Kunci)*
- **Kunci:** D
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Siklus bersifat berulang: setelah tahap execute selesai, program counter mengarahkan CPU mengambil instruksi berikutnya.
- **Umpan Balik Salah:** Komputer belum berhenti karena masih ada instruksi selanjutnya di daftar program.

---

#### [K3-5] Hubungan Simbiotik Memori & CPU (C2 - Pilihan Ganda Konseptual)
- **Pertanyaan:** Pernyataan yang paling tepat tentang peran kerja sama memori dan CPU saat program berjalan adalah …
  - A. CPU menyimpan seluruh program, sedangkan memori yang mengeksekusinya.
  - B. Memori menyimpan instruksi dan data, sedangkan CPU mengambil, menerjemahkan, dan menjalankannya. *(Kunci)*
  - C. Memori mengatur urutan instruksi, sedangkan CPU hanya menampilkan hasil ke monitor.
  - D. Memori dan CPU baru mulai bekerja setelah hasil ditampilkan ke layar.
- **Kunci:** B
- **Bobot Skor:** Benar = 1, Salah = 0 (Poin Kuis: 12)
- **Umpan Balik Benar:** Tepat! Memori berperan sebagai lumbung data/instruksi, dan CPU adalah motor pemroses yang aktif mengolahnya.

### 4.2 Latihan Soal Unit 3 (Bonus +2 Poin / Soal)

#### [L3-1] Fungsi Tahap Decode (C2 - Benar/Salah)
- **Pernyataan:** Tahap Baca (Decode) dilakukan oleh Unit Kendali (CU) untuk memahami arti perintah instruksi biner.
- **Pilihan:** Benar / Salah
- **Kunci:** Benar
- **Umpan Balik:** Tepat! Unit Kendali bertugas membedah opcode instruksi agar sirkuit yang tepat disiapkan.

#### [L3-2] Prediksi Tahap Berikutnya "MUL 4, 2" (C2 - Pilihan Ganda Prediksi)
- **Pertanyaan:** CPU baru selesai membaca (Decode) instruksi perkalian `MUL 4, 2`. Tahap berikutnya adalah …
  - A. Mengambil instruksi berikutnya dari RAM
  - B. Menjalankan instruksi (Execute): ALU mengalikan 4 × 2 menghasilkan 8 *(Kunci)*
  - C. Program langsung selesai
  - D. Membaca ulang instruksi yang sama
- **Kunci:** B
- **Umpan Balik:** Tepat! Setelah tahap Decode selesai, siklus wajib melangkah ke Execute sebelum mengambil instruksi baru.

#### [L3-3] Menjodohkan 3 Siklus FDE (C1–C2 - Menjodohkan)
- **Pasangan:**
  - Ambil (Fetch) ➔ CPU menyalin instruksi dari memori RAM
  - Baca (Decode) ➔ Unit Kendali mengurai maksud instruksi
  - Jalankan (Execute) ➔ Sirkuit komponen terkait (misal ALU) mengerjakan perintah

#### [L3-4] Bagian Aktif pada Instruksi Simpan (C2 - Pilihan Ganda)

  - A. Printer
  - B. Keyboard
  - C. Memori Utama (RAM) *(Kunci)*
  - D. Layar Monitor
- **Kunci:** C
- **Umpan Balik:** Tepat! Perintah menyimpan ditujukan ke alamat memori utama.

#### [L3-5] Mengapa Disebut Siklus? (C2 - Pilihan Ganda)
- **Pertanyaan:** Mengapa proses Ambil, Baca, Jalankan disebut sebagai sebuah “siklus” yang berulang?
  - A. Karena memori cepat habis baterai
  - B. Karena CPU sering lupa instruksi sebelumnya
  - C. Karena ALU hanya bisa dipakai satu kali seumur hidup
  - D. Karena suatu program tersusun atas banyak instruksi yang harus dieksekusi satu per satu secara berurutan *(Kunci)*
- **Kunci:** D
- **Umpan Balik:** Tepat! Siklus berulang jutaan hingga miliaran kali per detik (clock rate) untuk menyelesaikan program baris demi baris.
